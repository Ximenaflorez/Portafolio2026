## 3. Solution architecture

- **Methodology:** Spec-Driven Development with Spec Kit: constitution, specification, plan, tasks and implementation.
- **Stack:** React with Vite, SASS and Tailwind CSS, Git.
- **Design system:** central tokens for color, typography (Manrope and Inter, 1.25 scale) and spacing (8px base).
- **Component structure:** Atomic Design in five layers: atoms, molecules, organisms, templates and pages.
- **Accessibility:** WCAG 2.2 AA: keyboard, visible focus, ARIA only when HTML is not enough, validated contrast.
